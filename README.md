### // building

[**NerdLMS**](https://github.com/nerdresolve/NerdLMS) is a multi-tenant learning platform, in active development under my own company, NerdResolve. Next.js 15 and React 19 up front, a use-case-driven backend that keeps domain logic framework-free, Postgres underneath, and whitelabel support so each install ships under its own brand and domain. Open source, and the code is there to read.
