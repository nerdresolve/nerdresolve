### // building

[**NerdLMS**](https://github.com/nerdresolve/NerdLMS) is a multi-tenant learning platform I'm building under my own company, NerdResolve. Stack: Next.js 15, React 19, Postgres, and a backend organized around use cases, with domain logic kept framework-free. Whitelabel support, so each client runs under its own brand and domain. Open source, code's public.
